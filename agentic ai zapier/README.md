# AI-Powered Operations Agent Using AI by Zapier

## Project Overview

This project develops a bounded AI-powered operations agent using AI by Zapier. The agent receives synthetic natural-language requests, extracts structured information, validates the request against predefined rules, and proposes actions in mock business systems.

Human approval is required before any simulated write operation.

## Project Aim

The aim of this project is to design and evaluate a transparent operations agent that can process common operational requests while maintaining human oversight and execution traces.

## Supported Request Types

The prototype focuses on three types of operational requests:

1. Meeting coordination.
2. Follow-up task creation.
3. Operations record updates.

## Project Scope

The project uses synthetic data and mock business systems. It does not access private accounts, send real messages, create real appointments, modify production databases, or make high-impact decisions.

## Proposed Technologies

- Zapier
- AI by Zapier
- Webhooks by Zapier or Google Forms
- Zapier Tables or Google Sheets
- Synthetic test data
- Python for optional evaluation analysis

## Project Status

The project is currently in the initial planning and scope-definition stage.
