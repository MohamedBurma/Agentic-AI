## 1. Project Title

AI-Powered Operations Agent Using AI by Zapier

## 2. Project Aim

The aim is to design and evaluate a transparent operations agent that can interpret synthetic requests, validate them against simple policies, and prepare actions while requiring human approval before simulated writes.

## 3. Project Objectives

- Receive a synthetic operational request.
- Classify the request into a supported request type.
- Extract important information from the request.
- Identify missing or ambiguous information.
- Validate the request against predefined policy rules.
- Propose actions in mock business systems.
- Require human approval before simulated write actions.
- Prevent duplicate actions.
- Record the processing steps in an execution trace.
- Evaluate the prototype using a small synthetic test set.


## 4. Out of Scope

The prototype will not:

- Access private email accounts.
- Send real email messages.
- Create real calendar events.
- Modify production databases.
